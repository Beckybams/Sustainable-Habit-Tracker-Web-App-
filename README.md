# 🌱 Sustainable Habit Tracker Web App

A simple and interactive web application designed to help users build, monitor, and maintain sustainable daily habits. The application encourages environmentally friendly lifestyle choices by allowing users to track activities and measure their progress over time.

## 📌 Project Overview

The **Sustainable Habit Tracker Web App** helps users monitor eco-friendly habits such as:

* ♻️ Recycling
* 💧 Saving water
* ⚡ Reducing energy consumption
* 🚶 Walking or cycling
* 🛍️ Using reusable products
* 🌱 Reducing waste

Users can record their daily activities and track their progress toward building a more sustainable lifestyle.

## ✨ Features

* Track daily sustainable habits
* Add and manage eco-friendly activities
* Monitor habit completion
* View sustainability progress
* Simple and user-friendly interface
* Encourages environmentally responsible behavior

## 🛠️ Technologies Used

This project can be developed using:

* **Python**
* **Pandas**
* **Streamlit**
* **HTML/CSS**
* **Synthetic Data**

## 📊 Dataset

The application uses synthetic data to simulate sustainable habits and user activities.

Example data fields include:

| Column    | Description                               |
| --------- | ----------------------------------------- |
| User_ID   | Unique identifier for each user           |
| Date      | Date of activity                          |
| Habit     | Sustainable habit performed               |
| Category  | Type of sustainable activity              |
| Completed | Indicates whether the habit was completed |
| Points    | Sustainability points earned              |

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/Beckybams/Sustainable-Habit-Tracker-Web-App-.git
```

Navigate to the project folder:

```bash
cd Sustainable-Habit-Tracker-Web-App-
```

Install the required dependencies:

```bash
pip install pandas streamlit
```

Run the application:

```bash
streamlit run app.py
```
